# Security Policy

## Supported Versions

| Version | Supported          |
|---------|-------------------|
| 1.x     | ✅ Active support |

## Reporting a Vulnerability

This project deals only with local audio playback and has no network-facing
surface beyond downloading sound files from public soundboard websites.

If you discover a security issue:

1. **Do not** open a public GitHub issue
2. Send details to the maintainer via [GitHub Security Advisories](https://github.com/evanokeefe39/pi-rts-alerts/security/advisories/new)
3. You should receive a response within 48 hours

### What to include

- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Any suggested fix (if applicable)

### Scope

- Sound download URLs going to unexpected hosts
- Arbitrary code execution via sound file paths
- Privilege escalation or sandbox escape

---

We take all security reports seriously and will acknowledge receipt within
48 hours and provide a timeline for a fix.
